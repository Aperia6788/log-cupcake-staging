로그 표시 방식

이미지 저장에는 선택한 글꼴이 그대로 담깁니다. HTML 붙여넣기는 게시글에서 지원하는 글꼴 또는 기기의 대체 글꼴로 표시됩니다. ‘바로 쓰는 글꼴’ 외에는 고른 순간에만 내려받으니 처음 한 번은 잠깐 기본 글꼴로 보일 수 있어요.

영문 장식 글꼴은 영어 제목용이에요. 한글 글자는 명조로 대신 보여요.

추가 캐릭터는 각자의 말풍선 배경색을 그대로 씁니다. 배경은 화자를 따르고 글자색은 대사 종류(대사·생각·통신)를 따릅니다.

말풍선 없이 본문을 이어 읽습니다. 추가 캐릭터는 이름 색을 사용하고, 생각·통신 색은 기존 설정을 따릅니다.

미리보기·📷 이미지 저장에선 표지 위에 겹쳐 보여요. 아카라이브는 글 저장 때 겹치기를 지워 버려서, ✨ 복사·HTML로 붙여넣으면 표지 바로 아래 칸으로 들어가요.

원본 비율로 표시합니다. 이름·소개는 이름을 바꿨거나 사진·소개가 있는 쪽만 반투명 칸에 올라가고(기본 이름 AI·USER 그대로면 안 나와요), 프로필 사진은 표지가 대신합니다. 2분할로 돌아가면 기존 프로필 사진과 소개가 다시 나타납니다.
